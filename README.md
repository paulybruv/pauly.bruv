# Pauly Bruv Engraving

Pauly Bruv Engraving is a single-page interactive showcase and commission portal for bespoke laser-crafted products based in Chelmsley Wood, Birmingham. Built with semantic HTML5, Bootstrap 5, and custom CSS, the website highlights custom tactical football slate coasters, 3D MDF street signs, Brummie slang magnets, and point-of-sale displays.

## User Experience (UX)

### Strategy & Target Audience

- **Football Enthusiasts:** Looking for tactical slate coasters commemorating iconic matches.
- **Homeowners & Bar Owners:** Seeking customized 3D layered MDF street signs or pub signage.
- **Gift Buyers:** Looking for personalized, authentic Birmingham gifts and laser-cut keepsakes.
- **Local Businesses:** Inquiring about custom branded merchandise and point-of-sale displays.

### User Stories

- **US01 (Hero & Brand Introduction):** As a first-time visitor, I want to immediately understand what Pauly Bruv Engraving creates so that I can decide whether to explore products or place an order.
- **US02 (Navigation & Smooth Scrolling):** As a user, I want an intuitive sticky navigation bar so that I can jump seamlessly between products, maker bio, social channels, and the contact form.
- **US03 (Featured Products Gallery):** As a potential buyer, I want to view core product lines with starting prices, clear photos, and concise specifications so that I can evaluate what to purchase.
- **US04 (About the Maker):** As a customer, I want to read the artisan's workshop background and tools (Atomstack X7, LightBurn) to feel confident in the build quality.
- **US05 (Social Community & Follow):** As a visitor, I want direct links to TikTok, Instagram, and Facebook so that I can watch behind-the-scenes laser crafting videos.
- **US06 (Interactive Custom Order Form):** As a client with a custom idea, I want an accessible commission inquiry form so that I can request a quote with specific materials and dimensions.

## Features

### Existing Features

- **SEO & Social Open Graph Metadata:** Complete `<head>` configuration with meta descriptions, viewport settings, and Open Graph previews for link sharing.
- **Sticky Navigation Bar:** Accessible Bootstrap 5 responsive navbar with branding and internal jump links.
- **Hero Banner:** Two-column introduction featuring core business copy, call-to-action buttons, and high-resolution product photography.

### Future Features in Progress

- **Interactive Product Showcase Cards:** 3-column responsive grid displaying street signs, slate coasters, and magnets.
- **Maker Story Section:** Narrative background on Birmingham workshop production and diode laser workflow.
- **Social Community Hub:** Cards linking out to TikTok, Instagram, and Facebook.
- **Commission Inquiry Form:** Accessible form inputs for custom quote inquiries.

- **HTML5:** Semantic page structuring.

## Deployment & Local Development

### GitHub Pages Deployment

1. Navigate to the repository settings tab on GitHub.
2. Select **Pages** in the left navigation menu.
3. Under **Build and deployment**, set the Source branch to `main` and root directory `/ (root)`.
4. Click **Save**; the live URL is published automatically.

### Local Development

To run this project locally:

```bash
git clone [https://github.com/paulybruv/paulybruv.github.io.git](https://github.com/paulybruv/paulybruv.github.io.git)
cd paulybruv.github.io
```
